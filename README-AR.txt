بناء تطبيق أندرويد (APK) وبرنامج ويندوز (EXE) — Smart Solutions ERP
==================================================================

الطريقة الموصى بها: البناء السحابي عبر GitHub (بدون تثبيت أي برامج)
------------------------------------------------------------------
1) أنشئ حساباً مجانياً على github.com ثم مستودعاً جديداً (New repository) باسم مثل smart-erp.
2) ارفع كل محتويات هذا المجلد إلى المستودع (Add file > Upload files) بما فيها مجلد .github
   (إن لم يظهر المجلد المخفي على ويندوز، فعّل «إظهار العناصر المخفية» قبل السحب).
3) افتح تبويب Actions داخل المستودع ثم اختر workflow باسم build ثم Run workflow.
4) انتظر 10 إلى 15 دقيقة. عند اكتمال التشغيل افتحه وانزل إلى قسم Artifacts:
   - android-apk : يحتوي app-debug.apk  (تطبيق أندرويد)
   - windows-exe : يحتوي ملف التثبيت (Setup) ونسخة محمولة (Portable) لويندوز
5) إن فشلت خطوة، افتحها وانسخ نص الخطأ وأرسله لي.

تثبيت APK على الجوال: انقل الملف للجوال وافتحه، وفعّل «السماح بالتثبيت من مصادر غير معروفة» عند الطلب.
الـ APK هنا موقّع بمفتاح تجريبي (debug) ويصلح للاستخدام الشخصي. للنشر على Google Play يلزم توقيع إصدار رسمي.

البناء المحلي (اختياري)
-----------------------
ويندوز EXE: يلزم Node.js 16 أو أحدث ثم:  npm install  ثم  npm run dist:win   (الناتج في مجلد dist)
أندرويد APK: يلزم Node.js 18 وJDK 17 وAndroid Studio ثم:
   npm install ; npx cap add android ; npx cap sync android ; cd android ; gradlew assembleDebug

بديل أسهل لأندرويد: موقع pwabuilder.com — ضع رابط موقعك على Netlify وسيُنتج لك حزمة أندرويد.

توافق ويندوز
-------------
نسخة Electron المستخدمة (22) هي آخر نسخة تدعم ويندوز 7/8/8.1، لذلك يعمل البرنامج على جهازك (ويندوز 8) وعلى ويندوز 10/11.

ملاحظات مهمة
-------------
- بيانات التطبيق الأصلي مستقلة عن بيانات الموقع في المتصفح. للنقل استخدم: النسخ الاحتياطي ثم الاستعادة.
- في أندرويد: تصدير النسخ الاحتياطية وملفات Excel/PDF يمر عبر نافذة «مشاركة» لحفظ الملف أو إرساله.
- في أندرويد: الطباعة المباشرة والإدخال الصوتي وفتح واتساب قد لا تعمل داخل التطبيق كما تعمل في المتصفح. تحتاج اختباراً على جوالك.
- لم أتمكن من تشغيل عملية البناء نفسها في بيئتي (لا إنترنت ولا Android SDK)، فالإعدادات غير مجرّبة فعلياً.
